## Что такое reflection metadata

В .NET каждая сборка (DLL/EXE) — это PE-файл, внутри которого помимо машинного кода (для managed — IL) лежат **таблицы метаданных** по спецификации ECMA-335: TypeDef, MethodDef, FieldDef, ParamDef, MemberRef и т.д. Это структурированное описание всех классов, методов, их сигнатур, атрибутов — без этого CLR вообще не смог бы работать с типами.

**Reflection** — это API (`System.Reflection`), который читает эти таблицы и даёт тебе объекты вроде `Type`, `MethodInfo`, `ParameterInfo` в рантайме. Обычная Reflection (`Assembly.Load`) грузит сборку полностью и может выполнить её код (статические конструкторы и т.п.) — поэтому для просто "посмотреть API" безопаснее `MetadataLoadContext`, который читает только метаданные, ничего не исполняя.

Короче: metadata — это данные внутри DLL, reflection — способ их прочитать программно.

## CLI-утилиты, которые сделают это за тебя

**1. ildasm** — входит в .NET SDK / Windows SDK

```
ildasm MyLib.dll /out=MyLib.il /text
```

Дампит все метаданные и IL в текстовый файл. Сигнатуры там есть, но формат "сырой" (IL-нотация, не C#), ИИ придётся привыкнуть к синтаксису.

**2. ilspycmd** — CLI-версия ILSpy, ставится как dotnet tool

```
dotnet tool install -g ilspycmd
ilspycmd MyLib.dll -o ./out
```

Декомпилирует прямо в читаемый C#-код (сигнатуры + структура классов) — для ИИ это удобнее всего, т.к. синтаксис привычный.

**3. Microsoft.DotNet.ApiCompat.Tool** (бывший apiport/GenAPI)

```
dotnet tool install -g Microsoft.DotNet.GenAPI.Tool
dotnet-genapi MyLib.dll -o MyLib.api.cs
```

Генерирует "заглушку" C#-файла только с публичным API (без тел методов) — по сути готовый .cs с сигнатурами, идеально для скармливания ИИ как контекст.

**4. monodis** (если кроссплатформенно, из Mono) — аналог ildasm под Linux/Mac.

## Что выбрать

Для твоей задачи (сигнатуры → в контекст ИИ) лучший вариант — **`dotnet-genapi`**: результат сразу валидный C#-код с публичными сигнатурами, компактно, без мусора реализации. Можно просто скриптом прогнать по всем нужным DLL и склеить/подать как файлы.

Если нужна интерактивность (ИИ сам запрашивает конкретный тип, а не грузит весь файл) — тогда оборачивай `dotnet-genapi` или `MetadataLoadContext`-код в MCP-сервер, как обсуждали.
