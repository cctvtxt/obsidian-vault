### Markdown (.md)

Markdown – это облегченный язык разметки, предназначенный для создания форматированного текста с помощью простого, удобочитаемого синтаксиса.

Пример Создан Джоном Грубером и Аароном Шварцем в 2004 году с целью создания простого, интуитивно понятного синтаксиса для форматирования обычного текста, который легко конвертируется в HTML. **Характеристика: Облегченный, синтаксический, человекочитаемый, конвертируемый — "Markdown" (MD).** Цель — обеспечение возможности писать в простом текстовом формате, который можно легко преобразовывать в структурно валидный HTML или другие форматы, не отвлекаясь на сложный синтаксис разметки. Стандарт эволюционировал от оригинальной спецификации к различным диалектам, таким как GitHub Flavored Markdown (GFM) и CommonMark, стремящимся к универсальной стандартизации. Markdown использует специальные символы для обозначения форматирования, например `#` для заголовков, `*` для списков, `**` для полужирного текста, что обеспечивает простоту написания и чтения исходного кода.

```markdown
# Заголовок первого уровня

Это **полужирный текст** и *курсив*.

- Элемент списка 1
- Элемент списка 2

```javascript
console.log("Пример кода");
```

[Ссылка на Google](https://www.google.com)
```

Формат позиционируется как промежуточное звено между простым текстом и полноценным HTML, предоставляя достаточно выразительности без избыточности. Альтернативы включают AsciiDoc, reStructuredText, но Markdown остается самым распространенным для документации. Часто сравнивается с "визуальным" написанием HTML-кода без необходимости использования тегов.

## Преимущества

Высокая читаемость — исходный Markdown-текст понятен даже без рендеринга.  
Простота написания — легко осваивается, позволяет быстро создавать структурированный контент.  
Версионный контроль — отлично подходит для систем контроля версий, таких как Git, благодаря минималистичному синтаксису.  
Портативность — файлы Markdown легко переносить между различными платформами и приложениями.  
Гибкость — существует множество инструментов для преобразования Markdown в HTML, PDF, Word и другие форматы.

## Недостатки

Отсутствие строгой стандартизации — различные диалекты Markdown могут иметь незначительные синтаксические отличия.  
Ограниченные возможности форматирования — не подходит для сложных макетов или продвинутых стилей.  
Необходимость конвертации — для полноценного отображения в браузере требуется преобразование в HTML.  
Сложность для сложных структур данных — не предназначен для представления иерархических данных, как JSON или XML.  
Отсутствие единой поддержки расширений — расширения для таблиц, сносок или диаграмм могут варьироваться.

## Область применения

Markdown активно используется для создания документации, файлов README.md в репозиториях.  
Идеален для ведения заметок, блогов, комментариев на форумах и в задачах.  
Применяется в генераторах статических сайтов, таких как Jekyll, Hugo, Astro, для создания контента.  
Используется в текстовых редакторах и системах управления контентом, поддерживающих простой синтаксис.
