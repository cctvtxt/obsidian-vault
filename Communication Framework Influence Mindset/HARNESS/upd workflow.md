## Решение 2: git-surgeon (инструмент, специально созданный для этой проблемы)

Разработчик raine создал  — CLI на Rust, который даёт AI-агентам неинтерактивный контроль над git на уровне отдельных ханков. Ключевые команды для вашего случая:

- **`fold`** — влить изменения из staging в более ранний коммит (аналог fixup, но программно)
- **`split`** — разбить существующий коммит на несколько, даже ретроспективно, по hunk-ID
- **`fixup`** — сложить изменения в ранний коммит
- **`undo`** — убрать отдельные ханки из прошлых коммитов 

Главное преимущество: стабильные hunk-ID на основе SHA-1, которые не меняются при сдвиге строк. Агент может ссылаться на конкретные куски кода между операциями. Есть встроенный skill для Claude Code — агент начинает использовать его автоматически. aiproductivity.ai +1

Подходит для вашего второго варианта (написать всё, потом разбить): `split` позволяет ретроспективно разбить «жирный» коммит на фокусные по семантике — с точностью до строк внутри ханка
