## Зачем вообще нужен локальный сервер

Можно ведь просто открыть `index.html` через `file://` в браузере? Технически — да, но получишь кучу проблем:

### 1. **CORS и Same-Origin Policy**

Браузер блокирует через `file://`:

- `fetch()` к API
- Загрузку ES-модулей (`import`)
- Работу с Service Workers
- Запросы к относительным путям

### 2. **ES-модули требуют HTTP**

JavaScript

```
import { foo } from './bar.js' // не работает через file://
```

---

## Что конкретно дает Vite

### 🔥 Hot Module Replacement (HMR)

Меняешь компонент — он **обновляется в браузере мгновенно**, без перезагрузки страницы и потери состояния (открытые модалки, введенные данные сохраняются).

### ⚡ Мгновенный старт

Vite не бандлит код в dev-режиме. Он отдает файлы браузеру **через нативные ES-модули** по запросу. Проект на 1000 файлов стартует за секунду, а не за минуту как у Webpack.

### 🔄 Транспиляция на лету

- TypeScript → JavaScript
- JSX/TSX → JS
- SCSS/Less → CSS
- Vue/Svelte SFC → JS

Всё компилируется автоматически при запросе файла.

### 🌐 Прокси для API

В `vite.config.js`:

JavaScript

```
server: {
  proxy: {
    '/api': 'http://localhost:8080'
  }
}
```

Это решает CORS при разработке — фронт думает, что бэк на том же origin.

### 📁 Резолвинг путей и зависимостей

JavaScript

```
import React from 'react'  // Vite найдет в node_modules
import Btn from '@/components/Btn' // алиасы
```

### 🔐 Переменные окружения

`.env` файлы автоматически подхватываются (`import.meta.env.VITE_API_URL`).

### 📱 Доступ с других устройств

`vite --host` — открываешь приложение с телефона в той же сети для тестирования.

---

## Сравнение с альтернативами

|Подход|Скорость старта|HMR|Удобство|
|---|---|---|---|
|`file://`|мгновенно|❌|почти ничего не работает|
|`python -m http.server`|мгновенно|❌|только статика|
|Webpack dev-server|медленно|✅|бандлит всё сразу|
|**Vite**|мгновенно|✅|всё из коробки|

---

## Итог

Dev-сервер вроде Vite — это **среда разработки**, а не просто "раздача файлов". Он экономит часы работы за счет автоперезагрузки, мгновенной сборки, прокси и поддержки современных технологий без ручной настройки.
