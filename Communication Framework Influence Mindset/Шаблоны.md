
# КРИТЕРИИ УСПЕХА НАВЫКА

Навык считается освоенным когда ты можешь:

1. **СКОРОСТЬ**: Формулировать структурный ответ на любой вопрос за 60-90 сек без подготовки
2. **АДАПТИВНОСТЬ**: Отвечать на незнакомые вопросы логично (даже если не знаешь точного ответа)
3. **ЧИСТОТА**: Речь без слов-паразитов, с контролируемыми паузами
4. **СТРЕССОУСТОЙЧИВОСТЬ**: Сохранять структуру ответа даже при aggressive challenging
5. **УВЕРЕННОСТЬ**: Субъективное ощущение "я готов" на уровне 7+/10













|ТИП ВОПРОСА|СТРУКТУРА ОТВЕТА|ПРИМЕР СКЕЛЕТА|
|---|---|---|
|**ФАКТ**|Definition → Use case → Nuance|"X - это... Используется когда... Важно понимать что..."|
|**СРАВНЕНИЕ**|Similarities → Differences → When to use|"Оба решают... Различие в... Я бы выбрал X когда..."|
|**ПРОЦЕСС**|High-level → Steps → Edge cases|"В целом это работает так... Пошагово... При этом важно учесть..."|
|**ПРОБЛЕМА**|Understand → Options → Tradeoffs|"Сначала уточню контекст... Есть N подходов... Компромиссы..."|
|**ОПЫТ**|Situation → Action → Result → Learning|"Столкнулся с... Сделал... Получилось... Вынес урок..."|
|**ОЦЕНКА**|Criteria → Analysis → Conclusion|"Зависит от критериев... Если смотреть на... То..."|

| ТИП ВОПРОСА                            | СТРУКТУРА ОТВЕТА                                           | ПРИМЕР СКЕЛЕТА                                                                             |
| -------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **"Расскажите о себе"**                | Hook → Journey → Now → Future                              | "Начал с X... Прошёл путь через Y... Сейчас Z... Ищу возможность..."                       |
| **"Почему вы хотите работать у нас?"** | Research → Match → Contribution                            | "Изучил что вы делаете X... Это совпадает с моим Y... Могу принести Z..."                  |
| **"Расскажите о сложной задаче"**      | STAR (Situation-Task-Action-Result)                        | "Ситуация была... Задача... Я сделал... Результат..."                                      |
| **"Ваши слабые стороны?"**             | Real weakness → Mitigation → Progress                      | "У меня есть X... Работаю над этим через Y... Уже вижу прогресс Z..."                      |
| **"Почему ушли с прошлой работы?"**    | Neutral/Positive → Growth focus → Forward                  | "Достиг X... Ищу новые вызовы Y... Вижу их здесь..."                                       |
| **"Конфликт с коллегой"**              | Context → Your approach → Resolution → Learning            | "Была ситуация... Я подошёл так... Решили через... Вынес урок..."                          |
| **"Где видите себя через 5 лет?"**     | Direction → Skills → Value alignment                       | "Развиваюсь в направлении X... Хочу углубить Y... Вижу это в компании которая Z..."        |
| **"Почему мы должны вас нанять?"**     | Unique value → Proof → Fit                                 | "Моя уникальность в X... Подтверждается Y... Это нужно вам потому что Z..."                |
| **"Опишите идеального руководителя"**  | Balance → Examples → Flexibility                           | "Ценю баланс X и Y... Например... Но адаптируюсь под стиль..."                             |
| **"Ваши ожидания по зарплате?"**       | Research → Range → Flexibility → Value                     | "Изучил рынок - диапазон X-Y... Готов обсуждать... Главное - ценность роли..."             |
| **"Есть другие офферы?"**              | Honest → Non-specific → Timeline                           | "Нахожусь в процессе с несколькими компаниями... Но эта позиция приоритетна потому что..." |
| **"Расскажите о неудаче"**             | Specific failure → Accountability → Learning → Application | "Провалил X... Моя ответственность в Y... Понял Z... Теперь применяю..."                   |
| **"Как вы справляетесь со стрессом?"** | Acknowledge → Methods → Example                            | "Признаю что стресс есть... Использую X, Y методы... Пример когда сработало..."            |
| **"Работа в команде vs соло?"**        | Both → Situational → Examples                              | "Эффективен в обоих... Зависит от задачи... Пример команды... Пример соло..."              |
| **"Вопросы к нам?"**                   | Strategic questions (3-5 шт.)                              | "Какие главные вызовы? Как измеряется успех? Культура команды?"                            |
