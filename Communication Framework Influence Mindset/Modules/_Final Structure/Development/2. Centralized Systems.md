Монолит плюсы (до определенного масштаба)
- простота развертывания
- легкость внесения радикальных изменений
- простота тестирования
- простота деплоя
- прстота масштабирования
Монолит минусы
- трудно масштабировать (нет возможности просто усилить какую-то часть системы)
- медленная сборка, работа IDE
- сложность проекта
- большой TTM
- низкая надежность
- сложно переписывать составные части, расширять чтобы ничего не задеть
- элементы устаревают
Микросервисы плюсы:
- ci cd сложных приложений
- сервисы просто обслуживать, переписывать
- деплоятся независимо
- команды разработчиков автономны
- проще экспериментировать, откатывать изменения
- выше локализация проблем
Микросервисы минусы
- сложно адекватно разделить систему (может получиться распределенный по сети монолит)
- трудности распределенных систем (разработка, тестирование, деплой и так далее)
- Трудности согласования микросервисов для выполнения функции, которая затрагивает несколько из них
- новые сервисы снижают доступность системы (стабильность 0.99 перемножается)
- нужна сложная инфраструктура
- сложности выполнения транзакций, согласованность обработки данных

Решение 
- continouous development постоянный анализ системы (поели говна делаем иначе)
- адекватная декомпозиция


Монолит подходит для несложных систем с невысокой нагрузкой, микросервисы эффективнее для сложных масштабируемых приложений, но требуют серьёзной инфраструктуры, нет универсального решения — выбор архитектуры зависит от специфики бизнеса и сложности системы
